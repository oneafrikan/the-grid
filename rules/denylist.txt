# Opinion denylist for rules.py lint (E_OPINION). One case-insensitive Python `re`
# regex per line, searched against each single line of every rule file (never READMEs).
# Each line is first folded (NFKC, invisible characters dropped, whitespace runs collapsed
# to one space), so spacing and zero-width tricks cannot dodge a pattern; patterns that
# span words still use \s+ so they read correctly on their own. A scoped (?-i:...) makes
# one part case-sensitive: the product names ECC and Exa are, the ordinary words are not.
# Blank lines and lines starting with # are comments. Patterns are deliberately narrow:
# they catch house opinions by their specific phrasing and reject hedged bullets.
# Extend this file, not rules.py.
