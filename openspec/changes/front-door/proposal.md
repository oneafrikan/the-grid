## Why

A visitor cannot tell what the-grid is. The Pages site 404s, `index.html` has a hidden H1, no repo link and a 5.6 MB poster, and the README buries a good TL;DR under ASCII art, a film quote and ~300 lines of maintainer notes. The quickstart URL is a placeholder, there is no SECURITY.md, CONTRIBUTING.md, tag, About line or topics, and hand-synced counts drift. The project is meant to be public, so the front door has to carry the message.

## What Changes

- Rewrite `README.md` to ~150-180 lines in the author's first-person voice: hero line, who it's for, a copy-paste quickstart with the real clone URL and a "you should now see" check, outcomes, a mermaid architecture diagram, status. The Tron banner, Flynn quote and ASCII art stay.
- Move maintainer material out into `INSTALL.md`, `CONTRIBUTING.md`, `docs/architecture.md`, `docs/roadmap.md`, `docs/private-projects.md` (nothing is deleted, only relocated).
- Rebuild `index.html`: visible H1, copyable install command, GitHub and Star buttons, WebP hero under 300 KB, meta/OG/Twitter/canonical/favicon/JSON-LD, no hand-synced numbers.
- Stamp every headline count from the generated `SKILLS.md` headline into README and index.html via marker comments; gate fails on drift.
- Add `SECURITY.md`, `CONTRIBUTING.md`, `CHANGELOG.md`; close #7 (the LAMP build prompt is already retired by `depersonalise`).
- Add README-only translations (9 locales) generated by a script, marked machine-translated, with a hash-based staleness check.
- Add a reproducible `vhs` demo tape (bootstrap to `/tron`), a repo-metadata script (About, homepage, topics), and HUMAN tasks for copy/visual sign-off, rendering, applying metadata, and tagging `v0.1.0`.

## Capabilities

### New Capabilities

- `readme-front-door`: structure, copy and length contract for README.md and the doc split.
- `landing-page`: contract for index.html (SEO, hero, install, assets).
- `generated-counts`: single source of truth for headline numbers, stamped into docs.
- `readme-translations`: README-only machine translation with staleness detection.
- `trust-files`: SECURITY.md, CONTRIBUTING.md, CHANGELOG.md.
- `repo-metadata`: GitHub About, homepage and topics, applied by script.
- `demo-recording`: reproducible terminal demo from a vhs tape.

### Modified Capabilities

None. `openspec/specs/` is empty.

## Impact

- Files: `README.md`, `index.html`, `INSTALL.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CHANGELOG.md`, `docs/{architecture,roadmap,private-projects}.md`, `assets/*`, `the-grid.png` (deleted), `scripts/personal-allow-paths.txt`, `site-files.txt` (append site files, Q9), `tests/test_gate.bats`, `README.<locale>.md`, `scripts/{catalog.sh,gate.sh,stamp-counts.py,translate-readme.sh,check-translations.sh,build-site-assets.sh,repo-metadata.sh}`, `docs/demo/demo.tape`, new bats tests, `CLAUDE.md` key-files list.
- Depends on `foundations` (Pages serves, CI green, catalog counts corrected), `depersonalise` (personal residue and the LAMP prompt leave the repo; `the-grid.png` allowlisted until this change deletes it) and `manifest-lock-install` (BOOTSTRAP.md documents `grid install`).
- Folds in issue #25 (public README and quickstart) and #7 (LAMP build prompt fate).
- Use case for new assets: none are new asset types (docs, one site, one script set); all serve one use case, a first-time visitor deciding in 30 seconds whether this repo is for them.

## Non-goals

- No "why not ECC / gstack" comparison section, and the hero names no third-party tool.
- No translation of any doc other than README.md; `index.html`, USAGE.md, BOOTSTRAP.md stay English.
- No new install mechanism (`grid install` belongs to `manifest-lock-install`); the quickstart documents `bootstrap.sh --with-agents`.
- No stars, badges-for-vanity, sponsor blocks, Discord, or Discussions.
- No analytics or third-party scripts on the site; no external fonts or CDNs.
- No marketplace/plugin packaging (`plugin-marketplace`) and no multi-harness claims beyond what ships (`multi-harness`).
- No auto-rendering of the demo GIF or auto-applying of GitHub settings in CI.
