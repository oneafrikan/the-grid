# Tasks

Conventions for every group: Bash (shellcheck-clean) or Python 3 stdlib; idempotent; comment generously; tests are bats under `tests/` using `common_setup` from `tests/helpers/setup.bash`; tests set `GRID_STATE_DIR`, `GRID_LEARNING_DIR`, `GRID_PRIVATE_DIR` and `GRID_RUN_LOG` to temp dirs and `GRID_HOST` to a fixed name, and never touch `~/.claude`, `~/.grid`, the real private repo or the network. Default verify command: `bash scripts/gate.sh`. Design reference for every schema, constant and command: `design.md` in this change.
