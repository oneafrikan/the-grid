Read `design.md` first: every judgement call is a `Decided:` line there. Each group is one PR to `next`. Conventions for every group: bash (shellcheck `-S warning` clean) or Python 3 stdlib; comment generously; tests are bats under `tests/` using `load helpers/setup`, never touch the real `~/.claude`, `~/.grid` or `~/.the-grid-private`, and never call a model.
