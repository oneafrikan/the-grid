# Tasks

Read `design.md` first: every judgement call is a `Decided:` line there, and the exact guard rules, fixture tables and test helpers are in its "Guard rules" and "Test harness" sections. Each group is one PR to `next`. Conventions for every group: bash (shellcheck `-S warning` clean) or Python 3 stdlib; comment generously; tests are bats under `tests/` using `load helpers/setup`, never touch the real `~/.claude`, `~/.grid` or `~/.the-grid-private`, and never call a model. Hook payloads and transcript lines in tests come from the group 0 fixtures through the `tests/helpers/hooks.bash` helpers, never from hand-typed JSON. Default verify command: `bash scripts/gate.sh`.
