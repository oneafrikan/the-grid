# the-grid — sources

> Generated by `scripts/sources.sh` from `.gitmodules`.
> **Do not edit by hand** — re-run `bash scripts/sources.sh` after adding or removing a submodule.
> Check for rot with `bash scripts/sources.sh --check` (HEADs every URL, non-zero exit on failure).

The canonical upstream for every repo the-grid tracks — one line per submodule, nothing else.
Tier is read from `baseline-submodules.txt` (baseline only, so this file stays machine-agnostic):

- **wired** — every skill in the repo is symlinked live on every machine.
- **partial** — only the skills named in the baseline are wired.
- **library** — indexed and searchable (`skill-scout`), not wired.

For the per-skill breakdown see [`SKILLS.md`](../SKILLS.md). For the frozen May-2026 research
bibliography (not maintained, kept for provenance) see [`reference-resources.md`](reference-resources.md).
