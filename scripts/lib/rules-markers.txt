# Marker lines of the managed rules block that scripts/rules.py writes into a harness
# instruction file. ONE list, read by scripts/rules.py (finding and replacing a block) and by
# scripts/lib/harness.sh (wire.sh's "does this file hold a block to remove" grep).
#
# Format: `BEGIN <whole line>` or `END <whole line>` (an HTML comment of printable ASCII);
# lines starting with `#` and blank lines are ignored.
#
# The FIRST BEGIN and the FIRST END are the current spelling: emit writes them. To reword a
# marker, put the new line FIRST and keep the old one below it as a retired spelling, so
# blocks written under the old wording are still found, removed and replaced. Never delete a
# spelling that has shipped; an unlisted block is treated as user text and never auto-removed.
