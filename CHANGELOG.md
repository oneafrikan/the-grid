## [0.1.0] - 2026-11-04

First tagged release. Versioned from here; v0.x may still break between tags.

- Added: skill wiring. `scripts/wire.sh` symlinks a curated allowlist (shared baseline plus an optional per-machine overlay) into `~/.claude/skills/`; the rest of the ecosystem is indexed in `SKILLS.md` and searchable with `/skill-scout`. `scripts/bootstrap.sh` boots a machine in one command, `scripts/reconcile.sh` moves stale shadow copies aside.
- Added: `agent-factory/` composes agent teams from `role x stack x skills` (`compose.py`, targets include Claude Code, OpenClaw, Codex, Gemini CLI, OpenCode and portable personas). Four public projects: `grid` (dev team), `core`, `finance-desk`, `learning-desk`; `/tron` is the front door.
- Added: Claude Code plugin bundles `grid-core` and `grid-agents` and a marketplace manifest, generated by `scripts/build-plugins.py` from `plugins/bundles.json`, with `docs/PLUGINS.md`.
- Added: `scripts/grid` (`install`, `lock`, `drift`, `doctor`, `repair`, `uninstall`) and `grid.lock`, for a submodule-free install with sha-pinned skills.
- Added: vetting. `scripts/audit.sh` / `scripts/audit.py` scan wired and owned content against `policy.yaml` before `wire.sh` touches any link and in the gate; `CURATION.md` records why each wired repo is trusted.
- Added: guard hooks with `off|minimal|standard|strict` profiles (`hooks/`, `agent-factory/deploy_hooks.py`), and an auto-handoff SessionEnd hook that `wire.sh` keeps in the user settings (on by default, opt out with `-hook:auto-handoff`).
- Added: opt-in coding-convention rule packs under `rules/`, wired with `rules:<pack>` entries (`docs/rules.md`), and opt-in wiring into other harnesses via `harness:<name>` entries (`docs/harnesses.md`).
- Added: instincts, opt-in habit learning from your own sessions (`scripts/instincts.sh`, `docs/instincts.md`); usage tracking and a read-only prune report (`docs/usage.md`).
- Added: the issue-loop automation pattern (`automation-factory/patterns/issue-loop/`, cut into a repo with `scripts/instantiate.sh`) and `project-factory/` templates.
- Added: signals and knowledge conventions (`signals/`, `knowledge/`, `scripts/knowledge.py`) with a lint in `scripts/map.py --check`, and the generated session-start `MAP.md`.
- Added: macOS support. The bats suite and hook guards run on bash 3.2 and BSD userland; the rules are in `docs/portability.md`.
- Added: skill, agent and role counts in the README and site are generated from `SKILLS.md` and the agent examples instead of typed by hand, with a gate check for drift.
- Added: `INSTALL.md`, `CONTRIBUTING.md`, `docs/architecture.md`, `docs/roadmap.md` and `docs/private-projects.md`, split out of the README and `BOOTSTRAP.md`, with drift-guard tests.
- Added: `SECURITY.md` (what the scripts write, private vulnerability reporting, supported versions) and this changelog.
- Added: `scripts/repo-metadata.sh` (checks the GitHub repo description and topics) and `scripts/build-site-assets.sh` (favicon and site assets).
- Added: a README translation pipeline (`scripts/translate-readme.sh`, `scripts/check-translations.sh`). No translations are generated for this release; the README language switcher is empty.
