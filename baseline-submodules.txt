# BASELINE manifest — wired live into ~/.claude/skills on EVERY machine.
#
# This is the shared, machine-agnostic layer. A machine adds to (or subtracts
# from) it via a per-machine OVERLAY at machines/<hostname>.txt (host = `hostname
# -s`). wire.sh unions baseline + overlay; catalog.sh reads the BASELINE ONLY, so
# SKILLS.md stays a deterministic, machine-agnostic index. Keep this list tight —
# everything here loads on every box.
#
# Every OTHER repo under repos/ is LIBRARY-ONLY: indexed in SKILLS.md and
# searchable by skill-scout, but NOT symlinked into your active skill set.
#
# Entry grammar (same in the overlay):
#   repo-name            → wire ALL skills in that submodule
#   repo-name/skill      → wire ONLY that specific skill
#   project:<name>       → wire a composed agent-factory project's CC output
#   -repo | -repo/skill  → SUBTRACT (overlay escape hatch — remove a baseline entry)
#   -project:<name>      → un-gate a project
#
# Precedence: repos are wired alphabetically; later wins on name collision.
# Intentional order: anthropic → gstack → jeffallan → mattpocock → superpowers.
# gstack beats mattpocock by design — if both list the same skill name,
# remove the mattpocock entry here so gstack's version is served.
# Current gstack-wins resolutions: qa, review.
#
# To apply changes: bash ~/.the-grid/scripts/wire.sh
#
# Legacy fallbacks: if NO manifest file exists at all, ALL repos are wired; if
# NO project: entry exists anywhere, ALL composed projects are wired.
