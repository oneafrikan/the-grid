# MEMORY.md: What to Remember

Index of what agents on this project should remember across sessions. It points at the detail; it holds none.
What goes here: a short "remember this" line per item, with where the detail lives and why it matters. What does not: lessons (LEARNINGS.md), decisions (DECISIONS.md), current state (CONTEXT.md), or any detail copied from them.

This is the project's tracked, shared index. It is not Claude Code's personal auto-memory file (`~/.claude/projects/<project>/memory/MEMORY.md`), which is per user and untracked.
It differs from LEARNINGS.md: LEARNINGS.md holds the lessons themselves; this file only says which ones (and which other facts) to keep in mind, and where to find them.

Read at session start, so keep it under ~30 lines. Point only at files that exist. Drop a row when it stops mattering.
