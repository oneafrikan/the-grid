# CHANGELOG.md: What Changed

Record of changes that affect how the project is used or how it behaves, newest first.
What goes here: a user- or operator-visible change. What does not: why it was chosen (DECISIONS.md), where logs live (LOGS.md), or every commit (git history).

Rules:
- Record changes that affect how the project is used or behaves, not every commit.
- When a decision lies behind a change, link its DECISIONS.md entry, e.g. `(see DECISIONS.md, 2026-01-15 Short title)`.
- Group entries under Added / Changed / Fixed / Removed; leave out empty groups.
- This is the one file that grows without bound. Move old years to `docs/changelog-archive/<year>.md`. Sessions must not read the archive unless asked.
