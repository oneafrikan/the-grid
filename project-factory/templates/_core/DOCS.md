# DOCS.md: Where the Documentation Is

Index of the documentation a session should consult. It points at docs; it stores none.
What goes here: a pointer per document, with when to read it and how far to trust it. What does not: the documentation itself, a list of this project's own files (MAP.md) or of logs and handoffs (LOGS.md).

Rule: read the listed doc before guessing; if the doc does not cover it, say so.
