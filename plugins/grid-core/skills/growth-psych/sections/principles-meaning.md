# Principles: Meaning-making (32)

How people interpret what they see and decide what it is worth. Use for proof, offer, positioning, copy and trust. Definitions are our own wording.

| Principle | Meaning | Check (page, flow or test) |
|---|---|---|
| Social Proof | People take cues from what others do. | Logos, counts, reviews: specific, credible, near decision points? |
| Scarcity | Limited availability raises perceived value. | Real caps, dates or stock stated? Invented scarcity is a trust finding. |
| Curiosity Gap | A visible hole in knowledge creates the urge to fill it. | Teasers that earn the scroll or next step, not clickbait. |
| Mental Model | People arrive with a picture of how this kind of thing works. | Conventions respected (pricing, navigation, checkout steps)? |
| Familiarity Bias | The known feels safer than the new. | New thing explained via a known one ("like X, for Y"); layouts that confuse. |
| Skeuomorphism | Echoing real-world objects eases understanding. | Visuals borrowing a familiar object (ticket, receipt, calendar) where it helps. |
| Reciprocity | A favour creates a felt obligation to return it. | Free value (guide, tool, sample, trial) before the ask? |
| Singularity Effect | One identifiable person moves us more than a statistic. | A named person's story vs "10,000 customers"; a human behind the product. |
| Variable Reward | Unpredictable good surprises are especially engaging. | A surprise bonus, unlock or discovery; use sparingly. |
| Aha! Moment | The instant value becomes real to the person. | Can they experience value (demo, preview, first result) rather than read claims? |
| Goal Gradient Effect | Effort quickens as the finish line nears. | Progress shown in multi-step forms and onboarding; "one step left". |
| Occam's Razor | The simplest adequate design wins. | Anything not serving the goal is a deletion candidate. |
| Noble Edge Effect | Principled organisations are preferred. | Genuine mission, impact or ethics evidence, only if true. |
| Hawthorne Effect | Being observed changes behaviour. | Mostly research-side: does monitoring copy make people self-conscious? |
| Halo Effect | One strong impression colours the rest. | Strong brand, press or credential up top; one typo casting a negative halo. |
| Miller's Law | Short-term memory holds only a handful of items. | Twelve bullets become 3-5 groups; short menus and plan tables. |
| Unit Bias | A single unit feels like the right amount. | Offer packaged as one complete thing; one-step actions. |
| Flow State | Absorbed focus makes time vanish. | An uninterrupted path through the page or task, no jolts. |
| Authority Bias | Experts' views carry extra weight. | Credentials, certifications, endorsements: specific and verifiable? |
| Pseudo-Set Framing | Items framed as a set feel worth completing. | "3 of 5 done", bundles shown as collections. |
| Group Attractiveness Effect | Items look better in a group than alone. | Extras shown stacked with the main offer. |
| Curse of Knowledge | Experts forget what it is like not to know. | Insider jargon in headlines and labels; would a newcomer follow every word? |
| Self-Initiated Triggers | Reminders people set themselves get honoured. | "Remind me" or "notify me" for visitors who are not ready. |
| Survey Bias | Self-reported answers skew towards what sounds acceptable. | Quoted survey results as proof: method and sample credible? |
| Cognitive Dissonance | Clashing beliefs or actions feel uncomfortable until resolved. | Tension the offer resolves? Contradictory claims? Post-action doubt handled? |
| Feedforward | Knowing what will happen before acting reduces fear. | After the click: time needed, cost, next step, refund or cancel terms. |
| Hindsight Bias | After the fact, outcomes look obvious. | Case studies implying guaranteed results. |
| Law of Similarity | Things that look alike are read as alike. | Same-type elements styled consistently; links not styled as buttons. |
| Law of Prägnanz | People reduce ambiguous shapes to their simplest reading. | Diagrams and layouts that read clearly, not as "complicated". |
| Streisand Effect | Hiding something draws more attention to it. | Known criticism or limits addressed openly (FAQ), not buried. |
| Spotlight Effect | People overestimate how much others notice them. | Copy that eases embarrassment ("no one sees your draft"). |
| Fresh Start Effect | Milestones spur new commitments. | Framing around new starts: new month, role, year, project. |
