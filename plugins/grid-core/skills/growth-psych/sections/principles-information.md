# Principles: Information processing (29)

How people perceive and filter what is in front of them. Use for heroes, layout, hierarchy, calls to action, forms and screens. Definitions are our own wording.

| Principle | Meaning | Check (page, flow or test) |
|---|---|---|
| Hick's Law | More options slow the decision. | One primary action per screen? Nav or rival offers leaking traffic? |
| Confirmation Bias | People favour evidence that fits what they already believe. | Does copy start from the visitor's existing belief before adding a new one? |
| Priming | Earlier cues colour how later ones are read. | Does the hero match the ad, email or search result that sent them? Title tag sets the right frame? |
| Cognitive Load | Every bit of thinking spends a limited budget. | Dense text, jargon, unlabelled icons, long forms. Could a tired visitor finish? |
| Anchoring Bias | The first number or claim seen becomes the reference point. | Is the first price, stat or plan shown the one you want judged against? |
| Nudge | Small cues steer a choice without removing options. | "Recommended" tags, highlighted defaults, cues pointing at the main action. |
| Progressive Disclosure | Show the basics first, detail on demand. | Specs, terms, advanced fields collapsed or linked, not dumped up front? |
| Fitts's Law | Big, nearby targets are quicker to hit. | Button size, mobile tap targets, a sticky action on long pages. |
| Banner Blindness | Anything shaped like an ad gets skipped. | Does key content look like an ad: banner-shaped, stock photo with overlay text? |
| Decoy Effect | A deliberately weaker option makes its neighbour look better. | Does a tier exist only to flatter the target tier? Honest, not a trick. |
| Framing | The same facts land differently depending on how they are put. | Per month vs per day; gain vs loss wording; "2,000 joined" vs "50 places left". |
| Attentional Bias | Whatever is already on someone's mind grabs attention first. | Loaded words (free, risk, deadline): deliberate, or accidental distraction? |
| Empathy Gap | Calm people underrate how much emotion drives behaviour. | Copy assumes a rational reader; is the visitor really anxious, rushed or sceptical? |
| Visual Anchors | Some elements pull the eye along a path. | Gaze direction, arrows, a contrast trail towards the action. |
| Von Restorff Effect | The odd one out is noticed and remembered. | Is the one thing that should stand out the most distinct element? |
| Visual Hierarchy | Size, weight and position set reading order. | Is the main headline dominant and the primary action visible without hunting? |
| Selective Attention | Focused people screen out whatever is off-task. | Popups, chat widgets or banners interrupting a form or checkout? |
| Survivorship Bias | Only successes are visible, so they look typical. | Proof from standout cases only? Typical outcomes disclosed? |
| Juxtaposition | Things placed together read as one unit. | Prices, captions, labels, buttons unambiguously tied to the right item? |
| Signifiers | Visual cues tell people what an element does. | Buttons look pressable, links look like links, video shows a play control. |
| Contrast | Higher visual weight draws the eye first. | Action contrast against its surroundings; low-contrast body text (also an accessibility fail). |
| External Trigger | A prompt in the interface says what to do next. | Labels name the outcome ("Get my quote"), not "Submit" or "Learn more". |
| Centre-Stage Effect | Given a row of options, people lean to the middle. | Is the target option centred in the choice set? |
| Law of Proximity | Nearby things are seen as related. | Proof beside its claim, guarantee beside the buy button, error beside the field. |
| Tesler's Law | Complexity cannot be removed, only moved, often onto the user. | Did simplifying cause vagueness ("smart platform") or push work onto the visitor? |
| Spark Effect | A tiny first step is far more likely to be taken. | Is the first ask small (preview, price, one field) or huge (call, card, full form)? |
| Feedback Loop | Actions need a visible, immediate response. | Submit confirmation, button and loading states, helpful errors. |
| Expectations Bias | What people expect shapes what they perceive. | Does the page visibly deliver what the link, ad or title promised? |
| Aesthetic-Usability Effect | Attractive interfaces feel easier and more trustworthy. | Dated or glitchy visuals undermining credibility; polish read as competence. |
